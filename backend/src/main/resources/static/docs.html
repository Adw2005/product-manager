POST /api/auth/login Autenticação e geração de token

Autenticação: Pública (não exige token)

Corpo da requisição (JSON):

{
  "username": "admin",
  "password": "admin123"
}

Resposta de Sucesso (200 OK):

{
  "token": "YWRtaW46MTc5NDM2MDI2ODEzNA.oYD8...",
  "username": "admin",
  "role": "ADMIN"
}
GET /api/products Listar todos os produtos ou buscar por nome

Autenticação: Bearer Token (Header: Authorization: Bearer <token>)

Parâmetros opcionais: ?search=termo (filtra produtos pelo nome)

Resposta de Sucesso (200 OK):

[
  {
    "id": 1,
    "name": "Notebook Ultra 15",
    "description": "Notebook para uso profissional, 16GB RAM, SSD 512GB",
    "category": "Eletrônicos",
    "price": 4599.90,
    "stock": 12,
    "createdAt": "2026-11-09T21:53:24",
    "updatedAt": "2026-11-09T21:53:24"
  }
]
GET /api/products/{id} Consultar produto específico por ID

Autenticação: Bearer Token

Resposta de Sucesso (200 OK): Objeto JSON do produto.

Resposta de Erro (404 Not Found): Produto não localizado.

POST /api/products Cadastrar novo produto

Autenticação: Bearer Token

Corpo da requisição (JSON):

{
  "name": "Monitor 27\" UltraWide",
  "description": "Monitor curvo 27 polegadas, resolução 2K",
  "category": "Eletrônicos",
  "price": 1899.00,
  "stock": 8
}

Resposta de Sucesso (201 Created): Objeto do produto salvo com o id gerado pelo MySQL.

Resposta de Validação (400 Bad Request): Mapa de campos com erros de validação.

PUT /api/products/{id} Atualizar produto existente

Autenticação: Bearer Token

Corpo da requisição (JSON): Dados atualizados do produto.

Resposta de Sucesso (200 OK): Objeto atualizado.

DELETE /api/products/{id} Excluir produto

Autenticação: Bearer Token

Resposta de Sucesso (204 No Content): Sem corpo (exclusão confirmada).

Resposta de Erro (404 Not Found): ID não existente.
